## Featured Project — GovernPilot

**A governed control plane for agentic AI.** A working proof-of-work that builds everything *around* the model that a federal or regulated buyer requires:

- Human-in-the-loop approval gates before any write-capable action
- Server-enforced RBAC across local, JWT, and OIDC/JWKS identity
- Tamper-evident, hash-chained audit ledger with content-addressed evidence
- Policy-as-code with an OPA/Rego export; model gateway with cost/token/latency guardrails
- An open AI-governance specification with a machine-checkable **conformance suite** (L1 34/34 MUST + L2 14/14), an implementation-independent **test kit (TCK)**, and **auto-generated NIST RMF / FedRAMP evidence** validated against NIST's published 800-53 catalog
